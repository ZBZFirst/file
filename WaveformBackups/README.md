# UC Davis Puritan Bennett ventilator waveform backup

Source: [Puritan Bennett Ventilator Waveform Data on Zenodo](https://zenodo.org/records/14884306) (DOI: 10.5281/zenodo.14884306), published by UC Davis. Dataset license: GPL-3.0-or-later; see `DATA-LICENSE.txt`.

This directory contains byte-for-byte copies of the 145 CSV recordings from the downloaded Zenodo dataset. `SHA256SUMS` lists the checksum for each CSV. The copies are provided as an observation library source for the [ZeBeZo waveform atlas](https://www.zebezo.org/respiratory-therapy/ventilator-waveform-library/).

The filenames and date-like fields are de-identified or shifted. Virtual room and unit labels used in the atlas are display assignments, not actual clinical locations or confirmed patient identities. The CSVs contain flow and airway pressure waveforms; playback is observational only.
